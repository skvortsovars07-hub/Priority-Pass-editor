# Priority-Pass-editor
Priority Pass editor

- У каждого гостя нужно выбрать Mr или Ms. Если вписать обращение вручную (Mr Ivan Petrov), выбор пропадает.
- Работает как приложение на iPhone: открыть сайт в Safari → «Поделиться» → «На экран Домой».
- Кнопка «Поделиться / в Фото» открывает меню iOS: «Сохранить изображение» (в галерею), WhatsApp, Telegram и т. д.
- Скрин с QR выбирается прямо из галереи.
